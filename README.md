### 🌱 Smart Agriculture & IoT (UDAWA Ecosystem)

3. **[UDAWA-Gadadar](https://github.com/iwas108/UDAWA-Gadadar)**: Agent-based cyber-physical greenhouse automation system with real-time AC power consumption monitoring and relay instrumentation.

6. **[UDAWA-Murari](https://github.com/iwas108/UDAWA-Murari)**: Greenhouse microclimate surveillance node managing ambient temperature, humidity, VPD metrics, and automated ventilation.
7. **[UDAWA-Embedded-WebIface](https://github.com/iwas108/UDAWA-Embedded-WebIface)**: Lightweight on-chip embedded web server for offline sensor calibration, Wi-Fi captive portal setup, and local manual control.
