### 🤖 AI & Research Platforms
1. **[SLR-Magic](https://github.com/iwas108/SLR-Magic)** ([Live Demo](https://iwas108.github.io/SLR-Magic/)): Local-first, LLM-powered platform for Systematic Literature Reviews (SLRs) automating screening and extraction with human-in-the-loop precision.
2. **[Outliner](https://github.com/iwas108/Outliner)** ([Live Demo](https://iwas108.github.io/Outliner/)): Hierarchical thought-structuring tool and academic outliner designed for synthesizing research frameworks and thesis structures.

### 🌱 Smart Agriculture & IoT (UDAWA Ecosystem)
*UDAWA (Universal Digital Agriculture Workflow Assistant) is an open-source, modular cyber-physical platform for greenhouse automation and precision farming developed by Narin-Laboratory.*

3. **[UDAWA-Gadadar](https://github.com/iwas108/UDAWA-Gadadar)**: Agent-based cyber-physical greenhouse automation system with real-time AC power consumption monitoring and relay instrumentation.
4. **[UDAWA-Cloud-WebIface](https://github.com/iwas108/UDAWA-Cloud-WebIface)** ([Live Demo](https://cloud.udawa.or.id)): Centralized cloud telemetry dashboard and remote management interface for the UDAWA smart agriculture ecosystem.
5. **[UDAWA-Damodar](https://github.com/iwas108/UDAWA-Damodar)**: Hydroponic water quality and nutrient monitoring subsystem tracking EC/TDS, water temperature, and automated pump dosing.
6. **[UDAWA-Murari](https://github.com/iwas108/UDAWA-Murari)**: Greenhouse microclimate surveillance node managing ambient temperature, humidity, VPD metrics, and automated ventilation.
7. **[UDAWA-Embedded-WebIface](https://github.com/iwas108/UDAWA-Embedded-WebIface)**: Lightweight on-chip embedded web server for offline sensor calibration, Wi-Fi captive portal setup, and local manual control.

### 🎵 Media & Web Utilities
